# Централизованная конфигурация аспектов

Главный источник правды для аспектов находится в `scripts/vscripts/aspects/aspects_config.lua`.

## Как устроен аспект

Каждая запись в `AspectsConfig:GetSpellList()` сохраняет старый порядок и старые поля, чтобы не ломать сохранения игроков и существующий UI:

1. `id` аспекта / имя способности (`elf_spell_ms`);
2. иконка;
3. модификатор, который использует серверная логика;
4. localization / tooltip-ключи строк бонусов;
5. значения бонусов по уровням;
6. сторона (`"0"` — эльф, `"1"` — тролль);
7. включён ли аспект в текущем режиме;
8. стоимость уровней / legacy-стоимости.

Общие константы прокачки (`DEFAULT_MAX_LEVEL`, `UPGRADE_COST_STEP`, скидки до уровней 2/3) также находятся в этом файле.

## Как добавить новый аспект

1. Добавьте новую запись в нужную ветку `AspectsConfig:GetSpellList()` (`обычный режим`, `1x1` или `X4`).
2. Укажите уникальный `id`, иконку, модификатор, tooltip-ключи и значения по уровням.
3. Добавьте Lua-модификатор / способность, если аспект требует новой логики.
4. Добавьте localization-строки для названия и описания.

UI автоматически получит новый аспект через `CustomNetTables` (`game_spells_lib.aspects_config` и legacy `spell_list`).

## Как изменить баланс существующего аспекта

Измените значения в поле 5 соответствующей записи в `aspects_config.lua`. Эти значения используются:

- сервером как единая таблица аспектов;
- UI магазина аспектов;
- tooltip-ами, если localization-строка содержит шаблон `{value_1}`, `{value_2}` и т.д.

Пример шаблона описания: `Увеличивает скорость на {value_1}.` Для выбранного уровня UI подставит значение из первой строки значений аспекта.
